# AI 数字人直播助手（ai-live-desktop）

用你自己的视频和声音，在自己的电脑上做一个会说话的数字人主播。

准备几段真人视频和一份要讲的内容，软件会让视频里的人按内容开口说话，口型对得上，声音像本人，然后把画面送进抖音直播伴侣开播。全程在你自己的电脑上运行，不用联网，不按分钟收费，素材不会上传到任何地方。

> **目前还在开发中，暂时没有可下载的安装包。** 想第一时间用上，可以点右上角的 Star 关注，或者加文末的微信。

## 它能帮你做什么

- **让视频里的人开口说话**：上传一段真人出镜的视频，数字人就用这个形象直播，口型和说的话对得上。
- **用你自己的声音**：录几秒钟的声音，软件就能学会这个音色；不想录也可以直接选内置的声音。
- **自动回答弹幕**：把观众可能会问的问题和你的产品、人设告诉它，它会自己组织语言回答。
- **多段视频自然切换**：可以上传好几段视频轮流播放，切换的时候画面不会突然跳变。
- **直接接抖音直播伴侣**：不用装别的推流软件。

## 四步开播

1. **选形象**：上传一段或几段真人视频。
2. **选声音**：选一个内置声音，或者上传几秒录音克隆自己的声音。
3. **填内容**：写上人设、产品介绍，导入要回应的弹幕或讲解脚本，也可以直接套用模板。
4. **开播**：先在软件里试播看效果，满意后按图文引导连上直播伴侣。

不需要懂任何技术，也不需要调参数，软件会自动检测你的电脑并选好合适的设置。

## 需要什么样的电脑

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 或 Windows 11（64 位） |
| 显卡 | NVIDIA 独立显卡，显存 12G 或以上，例如 RTX 3060 12G |
| 内存 | 16G 或以上，建议 32G |
| 硬盘 | 预留 30G 以上空间 |

不确定自己的电脑行不行？软件第一次打开时会自动检查并告诉你结果。

笔记本、AMD 显卡、苹果电脑暂时不支持。

## 素材怎么准备效果最好

- **视频**：正脸、上半身、光线均匀，人不要离镜头太远，嘴巴不要被手或话筒挡住，时长 30 秒到几分钟都可以。
- **多段视频**：尽量在同一个地方、同一个机位、穿同一身衣服拍，这样切换时几乎看不出来。
- **声音**：在安静的环境里用正常语速说 5 到 10 秒，不要有背景音乐。

## 常见问题

**要花钱吗？**
软件免费开源。所有计算都在你自己的电脑上完成，没有按时长或按次数的费用。

**需要一直联网吗？**
只有第一次打开时需要联网下载必要的文件（约 10G），之后可以断网使用。直播本身当然还是需要网络的。

**我的视频和声音会被上传吗？**
不会。所有素材只保存在你自己的电脑上。

**可以用别人的视频和声音吗？**
必须先得到本人同意。未经授权使用他人的形象和声音是违法的。

**数字人直播符合平台规定吗？**
抖音要求 AI 生成的内容要做标识，不同类目还有各自的规则，开播前请先看一下平台的最新要求。
