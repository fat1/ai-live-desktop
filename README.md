# ai-live-desktop

全本地运行的 AI 数字人直播桌面应用（Windows）。

给定几段人物视频和一份弹幕/脚本，应用在本机完成回复生成、语音合成和口型驱动，把画面和声音输出到抖音直播伴侣。所有模型都在本地运行，不依赖云端接口，目标是在 RTX 3060 12G 上流畅运行。

> 项目处于早期开发阶段，目前正在搭建环境和做各模块的可行性验证，还不能直接使用。

## 设计目标

让没有技术背景的普通主播也能用：一键安装，自动适配电脑配置，按"选形象、选声音、填内容、开播"四步向导操作，界面上不出现技术名词。

## 功能规划

- **本地大模型回复**：根据弹幕内容和人设、话术配置生成回复。
- **声音克隆与预置音色**：可从人物视频或一段几秒的音频克隆音色，也可直接选用内置音色。
- **实时口型驱动**：以人物视频为底板，口型与合成语音同步。
- **多视频平滑切换**：支持上传多段视频，切换时自动寻找最佳切换点并生成过渡帧，画面不突变。
- **输出到直播伴侣**：默认用窗口捕获加系统声音，无需安装驱动；可选虚拟摄像头。
- **一键安装**：提供安装包，首次启动自动下载模型。

## 技术选型

| 环节 | 选型 |
|---|---|
| 大模型 | Qwen3-4B (GGUF) + llama.cpp |
| 语音合成 | GPT-SoVITS |
| 口型驱动 | MuseTalk 1.5 |
| 视频过渡 | RIFE 插帧 |
| 界面 | PySide6 |
| 运行环境 | Python 3.10、PyTorch + CUDA |

完整方案、显存预算和里程碑见 [docs/技术方案.md](docs/技术方案.md)。

## 硬件要求

- Windows 10/11 64 位
- NVIDIA 显卡，显存 12G 及以上（以 RTX 3060 12G 为基准）
- 内存 16G 及以上，建议 32G
